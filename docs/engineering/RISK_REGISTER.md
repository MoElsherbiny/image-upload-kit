# `img-upload-kit` — Risk Register

> Prioritized by verified evidence from Phase 0 inspection and updated through Phase 10 release readiness.

| ID | Severity | Affected Module(s) | Original Finding | Implemented Mitigation | Verification Evidence | Status |
| --- | --- | --- | --- | --- | --- | --- |
| **R-01** | **High** | `src/server/security/sanitizeSvg.ts`, `svgTokenizer.ts`, `svgAllowlist.ts` | Regex denylist (`FORBIDDEN_ELEMENTS`) could be bypassed by unlisted tags, namespace tricks, or malformed XML when `allowSvg: true`. | Replaced regex denylist with zero-dep XML tokenizer (`svgTokenizer.ts`) + strict tag/attribute/URI/CSS allowlist (`svgAllowlist.ts`, `sanitizeSvg.ts`) and optional `customSanitizer` hook. `allowSvg` remains `false` by default. | `tests/security/svg-adversarial.test.ts` & `tests/security.test.ts` (malformed XML, `<script>`, `<foreignObject>`, `<use>`, `on*`, CSS escapes, XXE/DOCTYPE/ENTITY). | **Mitigated** |
| **R-02** | **High** | `src/server/handler/presignRoute.ts`, `finalizeRoute.ts`, `uploadToken.ts`, `options.ts` | `PresignTokenPayload.sub` was unused; `finalizeRoute.ts` consumed `jti` before `runAuthorize`; no secret rotation or clock skew tolerance. | Added `getSubject` hook and `sub` claim binding; reordered `finalizeRoute.ts` to verify signature/expiry (`consume: false`), run `authorize`, check `sub` (`403`), and enforce rate limits *before* consuming `jti`; added `secret: string \| readonly string[]` rotation and `clockToleranceMs`. | `tests/security/token-lifecycle.test.ts` & `tests/presigned.test.ts` (cross-user `sub` mismatch, unauthorized burn prevention, replay `409`, rotation, expiry/clock skew). | **Mitigated** |
| **R-03** | **Medium** | `src/server/optimization/imageOptimizer.ts` | JPEG passthrough returned raw input buffer when `orientation <= 1`, leaking EXIF metadata (GPS, camera serial). | Strips EXIF/ICC metadata across all output paths including JPEG passthrough by default (`preserveMetadata: false`); explicit opt-in via `preserveMetadata: true`. | `tests/optimization-engine.test.ts` (verifies EXIF stripping on JPEG passthrough and opt-in preservation). | **Mitigated** |
| **R-04** | **Medium** | `src/server/security/imageLimits.ts`, `sniffFormat.ts`, `imageOptimizer.ts` | No independent `maxWidth`, `maxHeight`, or `maxFrames` guards prior to decoding animated or extreme-dimension payloads. | Added `imageLimits.ts` (`ImageResourceLimits`, `DEFAULT_IMAGE_RESOURCE_LIMITS`, `assertImageMetadataLimits`) enforcing `maxWidth`, `maxHeight`, `maxPixels`, and `maxFrames` before full decode, plus header/polyglot hardening in `sniffFormat.ts`. | `tests/security/image-limits-and-ratelimit.test.ts` & `tests/optimization-engine.test.ts`. | **Mitigated** |
| **R-05** | **Medium** | `src/storage/errorNormalizer.ts`, `s3Adapter.ts`, `supabaseAdapter.ts`, `localFsAdapter.ts` | S3/Supabase keys allowed traversal segments; `localFsAdapter` lacked `fs.realpath` symlink containment. | Centralized `sanitizeStorageKey` blocking `\0`, `.`, and `..` across S3 & Supabase adapters; added `assertRealPathContained` (`fs.realpath` + `lstat`/`readlink`) in `localFsAdapter.ts` and `validateStorageMetadata`. | `tests/storage/storage-hardening-and-migration.test.ts` & `tests/storage-adapters.test.ts`. | **Mitigated** |
| **R-06** | **Medium** | `src/types/errors.ts`, `src/types/rateLimit.ts`, `src/server/handler/responses.ts`, `rateLimitGuard.ts`, `memoryRateLimiter.ts` | Unstructured `{ error: string }` responses and no rate-limit/quota extension points. | Added `UploadKitError` (`UploadErrorCode`, `toPublicJSON()`, `isUploadKitError`, `isRetryableUploadError`), `Retry-After` headers, error redaction, `RateLimiter`/`QuotaProvider` interfaces, and dev `createMemoryRateLimiter`. | `tests/security/image-limits-and-ratelimit.test.ts` & `tests/server-raster-and-errors.test.ts`. | **Mitigated** |
| **R-07** | **Medium** | `src/cli/` (`detection/`, `capabilities/`, `recommendations/`, `filesystem/`, `generators/`, `validation/`, `commands/`) | CLI blindly installed `sharp` for frontend-only/edge projects with no infra detection or safe file generation. | Implemented 4-layer infra detection, runtime/storage capability registries, pure `architectureResolver`, runtime-safe `dependencyPlanner`, safe file/env/`AGENTS.md` managers (`--dry-run`, rollback), and `init`/`doctor`/`validate`/`agents`/`config` commands. | `tests/cli/cli-detection-and-recommendations.test.ts`, `cli-generators-and-safety.test.ts`, `cli-commands-and-fixtures.test.ts` (19 topologies). | **Mitigated** |
| **R-08** | **Low** | `package.json`, `pnpm-lock.yaml`, `.github/workflows/*.yml` | `pnpm audit` previously reported 8 dev-only advisories (`2` critical `tinypool`, `5` moderate `minimatch`/`glob`/`vitest`, `1` low `esbuild`) and CI used `npm install` without a lockfile. | Added `"packageManager": "pnpm@9.15.0"`, switched CI and Release workflows to `corepack enable` + `pnpm install --frozen-lockfile`, and pinned patched `tinypool` (`>=2.1.2`), `esbuild` (`>=0.28.1`), `glob` (`>=14.0.2`), and `minimatch` (`>=11.0.1`) via `pnpm.overrides` (`0` critical, `0` high, `3` moderate in dev-only `vitest`/`@vitest/mocker`, `0` low; `"dependencies": {}` has `0` runtime advisories). | `pnpm audit` + `scripts/check-dist.mjs`. | **Mitigated (0 critical/high)** |

## Independent Re-Audit Findings (`H-1`–`L-8`)

> Identified during the independent adversarial re-audit of `main @ e9499c9`. Status reflects branch remediation; coordinator verifies end-to-end on merged `main`.

| ID | Severity | Area | Finding | Remediation | Status |
| --- | --- | --- | --- | --- | --- |
| **H-1** | **High** | `multipartRoute.ts` | Multipart handler defaulted `allowClientPathOverride` to `true`, letting callers overwrite arbitrary keys. | Defaulted `allowClientPathOverride` to `false` with server-generated keys. | Fixed in re-audit remediation |
| **H-2** | **High** | `multipartRoute.ts` | Multipart allowed `application/octet-stream` and never verified object magic bytes on completion. | Restricted defaults to image MIME types and enabled `validateOnComplete: true` magic-byte check (deleting invalid objects). | Fixed in re-audit remediation |
| **H-3** | **High** | `resumableRoute.ts` | Resumable `init` stored `rawBucket \|\| defaultBucket`, ignoring preset buckets authorized during `init`. | Stored the exact resolved `authBucket` on the session and passed it to `uploadImage`. | Fixed in re-audit remediation |
| **M-1** | **Medium** | `rateLimitGuard.ts`, `SECURITY_GUIDE.md` | Rate limiter trusted spoofable `X-Forwarded-For` by default; docs showed raw XFF keying. | Added `trustProxy?: boolean \| number` (default `false`, right-most hop counting) and updated docs to `getSubject` keying. | Fixed in re-audit remediation |
| **M-2** | **Medium** | `uploader/index.ts`, `dedupe.ts` | Aborting the leader upload in in-flight dedupe coalescing aborted uncancelled concurrent callers. | Decoupled shared in-flight execution from per-caller `AbortSignal` waits. | Fixed in re-audit remediation |
| **M-3** | **Medium** | `storage/*.ts` | Storage `upload`/`delete`/`download` errors were not normalized, surfacing as generic HTTP 500s. | Applied `normalizeStorageError` across built-in adapter operations so retryable `STORAGE_*` codes propagate. | Fixed in re-audit remediation |
| **M-4** | **Medium** | `SECURITY_GUIDE.md`, `README.md` | No delete path-ownership guidance; `README` quick-start `Boolean(cookie)` allowed cross-user deletes if copied verbatim. | Added per-user `allowClientOverrides.folder` + `authorize` delete ownership recipe and explicit `README` placeholder warning. | Fixed in re-audit remediation |
| **M-5** | **Medium** | `SECURITY_GUIDE.md`, `presigned-and-dedupe.md` | Presigned staging defaults to target bucket; docs lacked private `stagingBucket` + 1-day lifecycle rule guidance. | Documented dedicated private `presigned.stagingBucket`, 1-day `_staging/` lifecycle expiration, and scheduled `sweepStagedUploads`. | Fixed in re-audit remediation |
| **M-6** | **Medium** | `resumableRoute.ts`, `finalizeRoute.ts` | Transient storage failures discarded resumable sessions and consumed/deleted presigned staged uploads. | Preserved resumable sessions and unconsumed presigned tokens/staged objects on retryable storage errors. | Fixed in re-audit remediation |
| **M-7** | **Medium** | `docs/*.md`, `tests/docs/` | 7 TypeScript API mismatches in `angular.md`, `FRAMEWORK_RECIPES.md`, and `react-native.md`. | Fixed all 7 doc mismatches and added `tests/docs/doc-examples-typecheck.test.ts` checking every block in an isolated program against `dist/*.d.ts`. | Fixed in re-audit remediation |
| **M-8** | **Medium** | `ci.yml`, `release.yml`, `package.json` | Workflows ran `npm install` ignoring `pnpm-lock.yaml`; `pnpm audit` had 2 critical, 5 moderate, 1 low dev advisories. | Added `"packageManager": "pnpm@9.15.0"`, switched workflows to `corepack enable` + `pnpm install --frozen-lockfile`, and pinned patched `tinypool`/`esbuild`/`glob`/`minimatch` (`0` critical, `0` high, `3` moderate dev-only `vitest`/`@vitest/mocker`, `0` low). | Fixed in re-audit remediation |
| **L-1** | **Low** | `uploader/`, `storage/` | Aborting after Sharp decode did not propagate `AbortSignal` into storage/variant/record steps. | Threaded `AbortSignal` checks and options through storage writes, variant uploads, and record hooks. | Fixed in re-audit remediation |
| **L-2** | **Low** | `finalizeRoute.ts`, `variantGenerator.ts` | Best-effort cleanup `.catch(() => {})` swallowed orphan-leaving storage delete errors silently. | Forwarded cleanup failures to `onError` hooks instead of silently discarding them. | Fixed in re-audit remediation |
| **L-3** | **Low** | `guards.ts`, `multipartRoute.ts` | Unsafe `as unknown as UploadHttpHandlerOptions` casts in handler helpers. | Replaced unsafe casts with narrowed structural option types. | Fixed in re-audit remediation |
| **L-4** | **Low** | `memoryAdapter.ts` | `createMemoryStorageAdapter` accepted `../` path segments, unlike other built-in adapters. | Enforced `sanitizeStorageKey` and `validateStorageMetadata` in `memoryAdapter.ts`. | Fixed in re-audit remediation |
| **L-5** | **Low** | `sanitizeSvg.ts` | Namespace-prefixed `<svg:svg>` root stripped prefix without ensuring default `xmlns`. | Injected `xmlns="http://www.w3.org/2000/svg"` on normalized `<svg>` roots when missing. | Fixed in re-audit remediation |
| **L-6** | **Low** | `src/cli/init.ts`, `src/cli/detect.ts` | `init --yes` reported `storage: 'local'` and `createLocalFsStorageAdapter` when GCS/Azure/Firebase was detected. | Reported `'custom'` (or detected S3/Supabase) in `RunInitResult.storage` and printed honest custom-adapter Quick Start snippets; added `cli-init-storage-reporting.test.ts`. | Fixed in re-audit remediation |
| **L-7** | **Low** | `multipartRoute.ts` | Re-uploading an existing part number double-counted bytes and had no default `maxTotalBytes`. | Tracked per-part byte sizes on replacement and enforced a `100 MB` default `maxTotalBytes` cap. | Fixed in re-audit remediation |
| **L-8** | **Low** | `CHANGELOG.md`, `docs/engineering/*.md`, `AGENTS.md` | Next release target (`2.3.0` minor) unnoted; readiness docs overstated `G-04`/`G-09` closure; `AGENTS.md` overstated multipart Sharp checks. | Targeted `[Unreleased]` as `2.3.0`, synced engineering registers with `H-1`–`L-8`, and aligned `AGENTS.md` & `SECURITY.md` with exact runtime behavior. | Fixed in re-audit remediation |
