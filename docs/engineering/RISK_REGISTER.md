# `img-upload-kit` — Risk Register

> Prioritized by verified evidence from Phase 0 inspection and updated through Phase 10 release readiness.

| ID | Severity | Affected Module(s) | Original Finding | Implemented Mitigation | Verification Evidence | Status |
| --- | --- | --- | --- | --- | --- | --- |
| **R-01** | **High** | `src/server/security/sanitizeSvg.ts`, `svgTokenizer.ts`, `svgAllowlist.ts` | Regex denylist (`FORBIDDEN_ELEMENTS`) could be bypassed by unlisted tags, namespace tricks, or malformed XML when `allowSvg: true`. | Replaced regex denylist with zero-dep XML tokenizer (`svgTokenizer.ts`) + strict tag/attribute/URI/CSS allowlist (`svgAllowlist.ts`, `sanitizeSvg.ts`) and optional `customSanitizer` hook. `allowSvg` remains `false` by default. | `tests/security/svg-adversarial.test.ts` & `tests/security.test.ts` (malformed XML, `<script>`, `<foreignObject>`, `<use>`, `on*`, CSS escapes, XXE/DOCTYPE/ENTITY). | **Mitigated** |
| **R-02** | **High** | `src/server/handler/presignRoute.ts`, `finalizeRoute.ts`, `uploadToken.ts`, `options.ts` | `PresignTokenPayload.sub` was unused; `finalizeRoute.ts` consumed `jti` before `runAuthorize`; no secret rotation or clock skew tolerance. | Added `getSubject` hook and `sub` claim binding; reordered `finalizeRoute.ts` to verify signature/expiry (`consume: false`), run `authorize`, check `sub` (`403`), and enforce rate limits *before* consuming `jti`; added `secret: string \| readonly string[]` rotation and `clockToleranceMs`. | `tests/security/token-lifecycle.test.ts` & `tests/presigned.test.ts` (cross-user `sub` mismatch, unauthorized burn prevention, replay `409`, rotation, expiry/clock skew). | **Mitigated** |
| **R-03** | **Medium** | `src/server/optimization/imageOptimizer.ts` | JPEG passthrough returned raw input buffer when `orientation <= 1`, leaking EXIF metadata (GPS, camera serial). | Strips EXIF/ICC metadata across all output paths including JPEG passthrough by default (`preserveMetadata: false`); explicit opt-in via `preserveMetadata: true`. | `tests/optimization-engine.test.ts` (verifies EXIF stripping on JPEG passthrough and opt-in preservation). | **Mitigated** |
| **R-04** | **Medium** | `src/server/security/imageLimits.ts`, `sniffFormat.ts`, `imageOptimizer.ts` | No independent `maxWidth`, `maxHeight`, or `maxFrames` guards prior to decoding animated or extreme-dimension payloads. | Added `imageLimits.ts` (`ImageResourceLimits`, `DEFAULT_IMAGE_RESOURCE_LIMITS`, `assertImageMetadataLimits`) enforcing `maxWidth`, `maxHeight`, `maxPixels`, and `maxFrames` before full decode, plus header/polyglot hardening in `sniffFormat.ts`. | `tests/security/image-limits-and-ratelimit.test.ts` & `tests/optimization-engine.test.ts`. | **Mitigated** |
| **R-05** | **Medium** | `src/storage/errorNormalizer.ts`, `s3Adapter.ts`, `supabaseAdapter.ts`, `localFsAdapter.ts` | S3/Supabase keys allowed traversal segments; `localFsAdapter` lacked `fs.realpath` symlink containment. | Centralized `sanitizeStorageKey` blocking `\0`, `.`, and `..` across S3 & Supabase adapters; added `assertRealPathContained` (`fs.realpath` + `lstat`/`readlink`) in `localFsAdapter.ts` and `validateStorageMetadata`. | `tests/storage/storage-hardening-and-migration.test.ts` & `tests/storage-adapters.test.ts`. | **Mitigated** |
| **R-06** | **Medium** | `src/types/errors.ts`, `src/types/rateLimit.ts`, `src/server/handler/responses.ts`, `rateLimitGuard.ts`, `memoryRateLimiter.ts` | Unstructured `{ error: string }` responses and no rate-limit/quota extension points. | Added `UploadKitError` (`UploadErrorCode`, `toPublicJSON()`, `isUploadKitError`, `isRetryableUploadError`), `Retry-After` headers, error redaction, `RateLimiter`/`QuotaProvider` interfaces, and dev `createMemoryRateLimiter`. | `tests/security/image-limits-and-ratelimit.test.ts` & `tests/server-raster-and-errors.test.ts`. | **Mitigated** |
| **R-07** | **Medium** | `src/cli/` (`detection/`, `capabilities/`, `recommendations/`, `filesystem/`, `generators/`, `validation/`, `commands/`) | CLI blindly installed `sharp` for frontend-only/edge projects with no infra detection or safe file generation. | Implemented 4-layer infra detection, runtime/storage capability registries, pure `architectureResolver`, runtime-safe `dependencyPlanner`, safe file/env/`AGENTS.md` managers (`--dry-run`, rollback), and `init`/`doctor`/`validate`/`agents`/`config` commands. | `tests/cli/cli-detection-and-recommendations.test.ts`, `cli-generators-and-safety.test.ts`, `cli-commands-and-fixtures.test.ts` (19 topologies). | **Mitigated** |
| **R-08** | **Low** | `pnpm-lock.yaml` (`devDependencies` only) | `pnpm audit` reports dev-only advisories in build/test tooling (`tinypool`, `minimatch`, `esbuild`). Published runtime `"dependencies": {}` has **0** advisories. | Zero consumer runtime exposure (`"dependencies": {}` is empty). Tracked for routine devDependency bumps when upstream Vitest/ESLint/tsup majors align with Node 20/22/24 CI. | `package.json` (`"dependencies": {}`) + `scripts/check-dist.mjs` dependency graph check. | **Low / Tracked** |
